--- title: OffscreenInstance shortdesc: Render the Giro3D scene in a worker and an offscreen canvas using the OffscreenInstance. attribution: © threejs.org tags: [offscreen, worker, gltf, performance] ---

This scene is not rendered on the main thread. The canvas below is transferred to a dedicated Worker via canvas.transferControlToOffscreen(), and the Worker owns an OffscreenInstance that loads a GLTF model with GLTFLoader, plays three independent AnimationMixer-driven animations, and renders every frame itself, no DOM. You can still drag/scroll to move the camera: three.js's control classes need DOM APIs an OffscreenCanvas doesn't have, so they can't run inside the Worker, but a normal MapControls instance drives a plain camera on this thread and its transform is mirrored into the Worker on every change.
